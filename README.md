# Memory Lane

**Memory Lane** is a beginner-level web application built using HTML, CSS, and JavaScript (with some assistance from AI). It allows users to capture, save, and revisit their memories in text, image, or video format.

## Features

- User authentication with login and signup
- Create and store text-based memories
- Upload and preview image memories
- Upload and watch video memories
- Search and filter memories by type and date
- Responsive design for desktop and mobile devices
- Simple, user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage for client-side data persistence
